# 🌳 AVL Tree Visualizer

An interactive web-based application that visualizes **AVL Tree operations** and helps users understand how self-balancing binary search trees work.

## ✨ Features

- **Insert Nodes:** Add new values to the AVL tree.
- **Delete Nodes:** Remove existing values from the tree.
- **Clear Tree:** Remove all nodes and start again.
- **Automatic Balancing:** Maintains AVL tree balance after every insertion and deletion.
- **Balance Factor:** Displays the balance factor of each node.
- **Interactive Visualization:** View the tree structure and understand how nodes are arranged.
- **Error Handling:** Displays error messages for invalid operations.

## 📚 About AVL Trees

An AVL Tree is a self-balancing Binary Search Tree (BST) in which the height difference between the left and right subtrees of any node is at most 1.

It maintains balance using four rotation techniques:

- LL (Left-Left)
- RR (Right-Right)
- LR (Left-Right)
- RL (Right-Left)

## 🎯 Project Objective

The main objective of this project is to provide an interactive way to learn and understand AVL Tree operations, balancing techniques, and tree rotations through visual representation.
